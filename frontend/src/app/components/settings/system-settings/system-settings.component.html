Student ID Prefix

Choose the 3-letter prefix that begins every Student ID issued by the system

Every new student is assigned a Student ID with the format PREFIX###YYYY — where PREFIX is the value you set here, ### is a unique 3-digit number, and YYYY is the registration year.

Letters A–Z only. Will be padded with "X" or trimmed to exactly 3 characters.
Example of an ID a newly registered student will get this year.
⚠ Saving this change will renumber every existing Student ID to use the new prefix (the digit and year portions are preserved). Make sure parents and teachers are aware before saving.
